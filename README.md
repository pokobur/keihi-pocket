# 経費ポケット (Keihi Pocket)

毎月25日に定額支給される経費（60,000円）と前月からの繰越金を原資とし、5つの固定科目における予算の上限設定、日々の支出記録、残高のリアルタイム可視化、および前月残金の柔軟な振り分け（繰り越し）を行うWebアプリケーションです。

---

## 🌟 主な機能とビジネスロジック

1. **月次サイクル（毎月25日 〜 翌月24日）＆ 定額入金管理**
   - `2026年10月度` ＝ `2026-10-25 〜 2026-11-24` のように、毎月25日起算の会計サイクルで自動集計。
   - 毎月25日の定額入金（デフォルト **60,000円**）に加え、当月入金額の手動調整や臨時収入の追加にも対応。
   - 「10日締めまであと〇日」「次回入金（25日）まであと〇日」をリアルタイムにカウントダウン表示。

2. **5つの管理科目とリアルタイム消化率プログレスバー**
   - **食材費**（通常決済 / 初期予算 ¥20,000）
   - **消耗品費**（通常決済 / 初期予算 ¥10,000）
   - **ネット決済費**（クレジットカード払い・毎月10日締め / 初期予算 ¥15,000）
   - **図書費**（通常決済 / 初期予算 ¥5,000）
   - **貯金**（積立・予備費枠 / 初期予算 ¥10,000）
   - 消化率に応じた3段階カラーリング（`0〜79%: 緑（安全）`、`80〜99%: 黄/オレンジ（注意）`、`100%以上: 赤（予算超過アラート）`）。

3. **ネット決済費（クレジットカード毎月10日締め）の2軸集計**
   - **当月予算の消化計算（利用日ベース）:** 当月サイクル（25日〜翌24日）内の決済額をネット決済費の当月実質上限額からリアルタイム控除。
   - **カード請求確定額の集計（10日締めベース）:**
     - **10日締め確定額（次回引落額）:** 前月11日 〜 当月10日までのネット決済費利用分を合算表示（前月サイクル後半分＋当月サイクル前半分）。
     - **11日以降利用分（翌月10日締め予定分）:** 当月11日〜24日の利用分を区別して表示。

4. **前月残金の繰り越し・各科目への自由振り分け ＆ 期中予算振替**
   - `前月総残金 ＝ 前月総予算（60,000円 ＋ 前々月繰越） − 前月4科目支出合計 − 前月貯金確定額` を自動算出。
   - 未振分けプール金が `0円` になるまで5科目へ自由に配分可能。
   - **ワンクリック補助ショートカット:**
     - 「余った科目にそのまま据え置き（科目別自動繰越）」
     - 「全額を『貯金』に振り分け」
   - **期中の予算振替:** サイクルの途中（25日〜翌24日）でも科目間で予算枠（基本予算枠・繰越枠）を再振り分け可能。

## 🚀 起動・ビルド方法

```bash
cd /Users/py./Applications/keihi-pocket
npm run dev
```

ブラウザで `http://localhost:3005` を開いてご利用いただけます。
また、静的ビルド（`npm run build`）にも対応しています。
